# 📝 Python To-Do List

A simple **To-Do List application built using Python** as part of my beginner coding journey.

This project allows users to add tasks, view their tasks, delete tasks, and exit the program through a simple menu-driven interface.

## 🚀 Features

* ➕ Add a new task
* 👀 View all tasks
* 🗑️ Delete a task
* 🚪 Exit the application
* 🔄 Menu runs continuously until the user chooses to exit

## 💻 How It Works

When the program starts, it displays a menu:

```text
--- TO-DO LIST ---
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
```

The user can choose an option and manage their tasks through the menu.
